# Quickstart Validation Guide

## Prerequisites
- Node.js 22 LTS+
- pnpm 10+

## Setup
```bash
pnpm install
```

## Running the Application
```bash
pnpm dev
```
Navigate to `http://localhost:5173`. You should see the welcome page and the example feature.

## Quality Checks
Run formatting, linting, and type checking:
```bash
pnpm format:check
pnpm lint
pnpm typecheck
pnpm test:run
```
